## En bref

`show version` est la première commande à taper sur un équipement inconnu. Elle révèle la **version IOS**, le **modèle**, la **mémoire disponible** et la durée de fonctionnement depuis le dernier redémarrage.

## Syntaxe

<CodeBlock lang="cisco">
show version
</CodeBlock>

Aucun paramètre — la commande affiche toujours la sortie complète.

## Exemple de sortie annotée

<CliPrompt mode="privileged" />

<CodeBlock lang="cisco" title="Sortie show version (routeur 2911)">

...

...

## Informations clés à repérer

| Champ | Signification |
|---|---|
| `IOS Software, Version` | Version complète de l'IOS |
| `cisco CISCO…` | Modèle matériel exact |
| `DRAM` | RAM principale (en Ko) |
| `CompactFlash` / `Flash` | Stockage de l'IOS (en Ko) |
| `Uptime` | Temps depuis le dernier redémarrage |
| `Configuration register` | Détermine le mode de démarrage |

## Registre de configuration

| Valeur | Comportement au démarrage |
|---|---|
| `0x2102` | Démarrage normal (charge l'IOS en Flash) |
| `0x2142` | Ignore la startup-config (mode password recovery) |
| `0x2100` | Démarre en ROM Monitor (rommon) |

<Callout type="tip" title="Vérifier la valeur attendue">
  Après une procédure de récupération de mot de passe, la valeur `0x2142` reste active. Pense à la remettre à `0x2102` avec `config-register 0x2102` en mode config.
</Callout>

## Pièges fréquents

<Callout type="warning" title="La version IOS détermine les fonctionnalités disponibles">
  Certaines commandes (ex: `crypto key generate rsa`) ne sont disponibles que sur des versions IOS avec la licence **Security** ou **Advanced IP Services**. Si une commande est inconnue, vérifie la version avec `show version`.
</Callout>
