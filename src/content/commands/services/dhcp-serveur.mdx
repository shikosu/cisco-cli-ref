## En bref

Un routeur Cisco peut jouer le rôle de **serveur DHCP** pour distribuer automatiquement les adresses IP, le masque, la passerelle et le DNS aux hôtes du réseau local. Cela évite de configurer chaque PC manuellement.

## Topologie de référence

<Topology>{`
    [PC1]──┐
    [PC2]──┤──[Switch]──[Router R1]──Internet
    [PC3]──┘

R1 : interface Gi0/0 : 192.168.1.1/24 (LAN)
     Pool DHCP : 192.168.1.10 → .254
     Exclure : .1 à .9 (adresses réservées)
`}</Topology>

## Syntaxe clé

<CodeBlock lang="cisco">
ip dhcp excluded-address &lt;début&gt; &lt;fin&gt;
ip dhcp pool &lt;nom&gt;
 network &lt;réseau&gt; &lt;masque&gt;
 default-router &lt;ip-gateway&gt;
 dns-server &lt;ip-dns&gt;
 lease &lt;jours&gt; &lt;heures&gt; &lt;minutes&gt;
</CodeBlock>

## Configuration complète

**1. Exclure les adresses réservées (à faire EN PREMIER)**

<CliPrompt mode="config" />

<CodeBlock lang="cisco">
Router(config)# ip dhcp excluded-address 192.168.1.1 192.168.1.9
</CodeBlock>

Les adresses .1 à .9 ne seront jamais distribuées aux clients.

**2. Créer le pool DHCP**

<CodeBlock lang="cisco">
Router(config)# ip dhcp pool LAN_PRINCIPAL
Router(dhcp-config)# network 192.168.1.0 255.255.255.0
Router(dhcp-config)# default-router 192.168.1.1
Router(dhcp-config)# dns-server 8.8.8.8 8.8.4.4
Router(dhcp-config)# lease 7
Router(dhcp-config)# exit
</CodeBlock>

**3. Vérifier que l'interface LAN est active**

<CodeBlock lang="cisco">
Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip address 192.168.1.1 255.255.255.0
Router(config-if)# no shutdown
</CodeBlock>

## Paramètres du pool

| Commande | Rôle |
|---|---|
| `network` | Plage d'adresses à distribuer |
| `default-router` | Passerelle transmise aux clients |
| `dns-server` | Serveur(s) DNS transmis aux clients |
| `lease` | Durée du bail (défaut : 1 jour) |
| `domain-name` | Suffixe DNS transmis aux clients |

## Pièges fréquents

<Callout type="danger" title="Toujours exclure les adresses réservées AVANT de créer le pool">
  Si tu crées le pool sans exclure l'IP de la gateway (ex: 192.168.1.1), le serveur DHCP pourrait distribuer cette IP à un client, provoquant un conflit d'adresse. Mets les exclusions en premier.
</Callout>

<Callout type="warning" title="Le DHCP est désactivé si aucun pool ne correspond à l'interface">
  Le routeur distribue des adresses DHCP uniquement si la plage du pool correspond au réseau de l'interface. Si l'interface est sur 192.168.1.0/24 et le pool sur 192.168.2.0/24, aucune adresse ne sera distribuée.
</Callout>

<Callout type="tip" title="Libérer les baux pour déboguer">
  Pour forcer un client à renouveler son adresse, utilise `clear ip dhcp binding *` (efface tous les baux) ou `clear ip dhcp binding &lt;ip&gt;`.
</Callout>
