## En bref

`service password-encryption` chiffre tous les mots de passe en clair visibles dans la `show running-config` — notamment les mots de passe console, VTY et `enable password`. Sans cette commande, ces mots de passe apparaissent en clair dans la config.

## Syntaxe

<CodeBlock lang="cisco">
service password-encryption
</CodeBlock>

Une seule commande, aucun paramètre. L'effet est immédiat et s'applique à tous les mots de passe actuels et futurs.

## Avant / après

<CliPrompt mode="config" />

<CodeBlock lang="cisco" title="Avant service password-encryption">
Router# show running-config
...
enable password cisco123       ← mot de passe en CLAIR
line console 0
 password monpass              ← mot de passe en CLAIR
 login
</CodeBlock>

<CodeBlock lang="cisco" title="Après service password-encryption">
Router(config)# service password-encryption
Router# show running-config
...
enable password 7 082D495C0D1E1C5C4F    ← chiffré type 7
line console 0
 password 7 14141B180F0B7B7977         ← chiffré type 7
 login
</CodeBlock>

Le préfixe `7` indique le type de chiffrement (type 7 = Vigenère, réversible).

## Étapes de configuration

**1. Vérifier l'état avant activation**

<CliPrompt mode="privileged" />

<CodeBlock lang="cisco">
Router# show running-config | include password
enable password cisco123
 password monpass
</CodeBlock>

**2. Activer le chiffrement**

<CliPrompt mode="config" />

<CodeBlock lang="cisco">
Router(config)# service password-encryption
</CodeBlock>

**3. Vérifier**

<CodeBlock lang="cisco">
Router(config)# end
Router# show running-config | include password
enable password 7 082D495C0D1E1C5C4F
 password 7 14141B180F0B7B7977
</CodeBlock>

**4. Sauvegarder**

<CodeBlock lang="cisco">
Router# copy running-config startup-config
</CodeBlock>

## Comparaison des types de chiffrement

| Type | Commande | Algorithme | Réversible ? |
|---|---|---|---|
| 0 | `password monpass` (sans service) | Aucun (clair) | N/A |
| 7 | `service password-encryption` | Vigenère | Oui (outils en ligne) |
| 5 | `enable secret monpass` | MD5 | Non |

## Pièges fréquents

<Callout type="danger" title="Le type 7 est réversible — ne pas s'y fier seul">
  Le chiffrement type 7 est un simple obfuscation. Des outils en ligne déchiffrent instantanément un hash type 7. N'utilise pas `enable password` + `service password-encryption` pour le mot de passe enable — utilise **`enable secret`** (type 5, MD5) à la place.
</Callout>

<Callout type="tip" title="Bonne pratique combinée">
  Utilise toujours les deux en même temps :
  1. `enable secret` pour le mot de passe enable (chiffrement MD5 fort)
  2. `service password-encryption` pour chiffrer les autres mots de passe (console, VTY)
</Callout>

<Callout type="warning" title="La désactivation ne déchiffre pas les mots de passe existants">
  Si tu fais `no service password-encryption`, les mots de passe déjà chiffrés restent chiffrés. Seuls les nouveaux mots de passe apparaîtront en clair.
</Callout>
