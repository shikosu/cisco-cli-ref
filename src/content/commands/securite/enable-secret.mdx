## En bref

La commande `enable secret` définit le mot de passe du **mode privilégié** (`#`). Sans elle, n'importe qui connecté en console ou Telnet peut taper `enable` et obtenir un accès total à l'équipement. C'est la **première commande de sécurité** à configurer sur tout équipement Cisco.

## Syntaxe

<CodeBlock lang="cisco">
enable secret &lt;mot-de-passe&gt;
</CodeBlock>

- `<mot-de-passe>` : sensible à la casse, 8–25 caractères recommandés
- Chiffré en **MD5** dans la running-config (contrairement à `enable password`)

## Exemple minimal

<CodeBlock lang="cisco" title="Définir le mot de passe enable">
Switch> enable
Switch# configure terminal
Switch(config)# enable secret Cisco@2024!
Switch(config)# end
Switch# write memory
</CodeBlock>

À la prochaine connexion console, taper `enable` demandera ce mot de passe.

## enable secret vs enable password

| Critère | `enable secret` | `enable password` |
|---------|-----------------|-------------------|
| Chiffrement | MD5 (type 5) | Aucun (texte clair) |
| Priorité | **Prioritaire** si les deux sont définis | Ignoré si `enable secret` présent |
| Usage | ✅ À utiliser | ❌ Obsolète |

<Callout type="danger" title="N'utilise jamais enable password">
  `enable password` stocke le mot de passe en clair dans la config. N'importe qui qui voit
  la running-config peut le lire. Utilise toujours `enable secret`.
</Callout>

## Étapes détaillées

**1. Passer en mode config**

<CodeBlock lang="cisco">
Switch> enable
Switch# configure terminal
</CodeBlock>

**2. Définir le secret**

Depuis <CliPrompt mode="config" /> :

<CodeBlock lang="cisco">
Switch(config)# enable secret Cisco@2024!
</CodeBlock>

**3. Vérifier dans la running-config**

<CodeBlock lang="cisco" title="Le hash MD5 est visible mais illisible">
Switch# show running-config | include enable
enable secret 5 $1$mERr$9cTjUIkIqozOAF0mDh7rz.
</CodeBlock>

Le `5` indique un hash MD5. Le mot de passe n'est jamais affiché en clair.

**4. Tester**

<CodeBlock lang="cisco" title="Tester le mot de passe">
Switch> enable
Password: ****
Switch#
</CodeBlock>

Le mot de passe n'est pas affiché à l'écran. Si incorrect : `% Access denied`.

## Vérification

<CodeBlock lang="cisco">
Switch# show running-config | include enable
enable secret 5 $1$mERr$9cTjUIkIqozOAF0mDh7rz.
</CodeBlock>

## Pièges fréquents

<Callout type="warning" title="Mot de passe oublié">
  Si tu oublies le mot de passe enable, il faut passer par la procédure de **password recovery**
  (accès physique console + séquence de démarrage spéciale). Évite les mots de passe
  trop complexes en TP.
</Callout>

<Callout type="tip" title="Convention TP">
  En TP, utilise un mot de passe simple et mémorisable, mais **différent** du mot de passe
  console pour reproduire une vraie architecture. Ex : `Cisco1234!` pour enable,
  `Console1!` pour la console.
</Callout>
