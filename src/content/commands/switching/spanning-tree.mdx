## En bref

STP (Spanning Tree Protocol) empêche les **boucles de couche 2** dans un réseau commuté avec des liens redondants. Sans STP, des trames pourraient circuler en boucle indéfiniment, saturant le réseau. STP élit un **root bridge** et bloque les ports redondants.

## Comment STP fonctionne

<Topology>
3 switches avec liens redondants :

    [SW1] ──── [SW2]
      │    \      │
      │     \     │
    [SW3] ──── ──[SW3]

STP élit SW1 comme Root Bridge (priorité la plus basse).
SW2 et SW3 bloquent les ports redondants (état BLK).
En cas de panne d'un lien, STP recalcule automatiquement.
</Topology>

**États des ports STP :**

| État | Description |
|---|---|
| Blocking (BLK) | Port bloqué, ne transmet pas de données |
| Listening | Écoute les BPDUs, ne transmet pas |
| Learning | Apprend les adresses MAC, ne transmet pas |
| Forwarding (FWD) | Transmet normalement |
| Disabled | Port administrativement désactivé |

## Syntaxe

<CodeBlock lang="cisco">
spanning-tree vlan &lt;id-vlan&gt; priority &lt;valeur&gt;
spanning-tree vlan &lt;id-vlan&gt; root primary
spanning-tree vlan &lt;id-vlan&gt; root secondary
</CodeBlock>

La priorité va de **0 à 61440** par incréments de 4096. Valeur par défaut : **32768**. Plus la priorité est basse, plus le switch est susceptible de devenir root bridge.

## Forcer l'élection du root bridge

**Méthode 1 — Commande simplifiée (recommandée)**

<CliPrompt mode="config" />

<CodeBlock lang="cisco" title="Forcer SW1 comme root bridge pour VLAN 1">
SW1(config)# spanning-tree vlan 1 root primary
</CodeBlock>

IOS choisit automatiquement une priorité inférieure à celle du root actuel.

**Méthode 2 — Priorité manuelle**

<CodeBlock lang="cisco">
SW1(config)# spanning-tree vlan 1 priority 4096
</CodeBlock>

**Root secondaire (backup)**

<CodeBlock lang="cisco">
SW2(config)# spanning-tree vlan 1 root secondary
</CodeBlock>

## PortFast — accélérer les accès clients

Sur les ports connectés à des PCs (pas des switches), PortFast passe directement à l'état Forwarding sans attendre les 30 secondes STP :

<CliPrompt mode="config-if" />

<CodeBlock lang="cisco" title="Activer PortFast sur un port access">
Switch(config)# interface FastEthernet0/1
Switch(config-if)# spanning-tree portfast
</CodeBlock>

## Pièges fréquents

<Callout type="danger" title="Ne jamais activer PortFast sur un port trunk ou connecté à un switch">
  PortFast sur un port trunk peut créer une boucle STP. Utilise-le **uniquement** sur les ports connectés à des hôtes finaux (PC, serveurs, imprimantes).
</Callout>

<Callout type="warning" title="La priorité doit être un multiple de 4096">
  Si tu entres une valeur qui n'est pas multiple de 4096 (ex: `1000`), IOS renvoie une erreur. Valeurs courantes : 4096, 8192, 12288, 16384, 28672, 32768.
</Callout>

<Callout type="tip" title="PVST+ — un STP par VLAN">
  Cisco utilise par défaut le **PVST+** (Per-VLAN Spanning Tree Plus). Cela signifie qu'il y a une instance STP indépendante par VLAN. Le root bridge peut être différent selon le VLAN.
</Callout>
